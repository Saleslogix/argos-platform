# Product Overview

Argos is a mobile web application framework for building enterprise CRM applications. The repository contains:

- **argos-sdk**: Core SDK providing the application framework, UI components, data management, and offline capabilities
- **argos-saleslogix**: SalesLogix CRM product built on top of the SDK

## Key Features

- Mobile-first web application framework
- Offline data synchronization with PouchDB
- SData protocol integration for backend communication
- Modular architecture with ApplicationModule system
- Customizable views (List, Detail, Edit)
- Redux state management
- Localization support (L20n)
- Service worker support for PWA capabilities

## Target Platform

Browser-based mobile web applications targeting enterprise CRM use cases, specifically SalesLogix CRM deployments.
